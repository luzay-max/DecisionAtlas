# Pilot Tier Comparison

[Pilot Kit](pilot-customer-delivery-kit.md) | [Commercial Baseline](self-hosted-commercial-baseline.md) | [License Boundary](self-hosted-license-and-support-boundary.md)

---

This comparison is a product and support packaging guide. It is not a runtime license enforcement table and does not replace a signed agreement.

| Area | Community | Team Self-hosted | Enterprise Self-hosted |
| --- | --- | --- | --- |
| Intended use | Local evaluation and public-repo proof | Small team private repository pilot | Private/offline deployment with operator support |
| Deployment | Local or demo stack | Customer-managed self-hosted package | Customer-managed private environment or assisted deployment |
| Repository scope | Public repos and demo data | Selected private repos under customer custody | Multiple private repos with enterprise process alignment |
| Team accounts | Bootstrap/local admin | Admin-created admin/reviewer/viewer accounts | Team workflow plus deployment/support operating procedures |
| Evidence | Local reports and smoke evidence | Release, readiness, clean install, benchmark, and handoff evidence | Evidence plus support/upgrade/recovery handoff |
| Support | Self-guided/community | Paid support boundary | Assisted deployment and custom support scope |
| Upgrade path | Manual | Manual package update with runbook | Assisted or reviewed upgrade plan |
| Pilot extension | Self-guided | Time-boxed support extension | Custom extension or enterprise evaluation scope |
| Runtime license enforcement | Deferred | Deferred | Deferred |

## Pilot Extension Path

If the initial pilot is not enough to decide:

1. Preserve current readiness evidence and handoff report.
2. Record unresolved blockers and non-pass states.
3. Define the next repository, workflow, or role boundary to test.
4. Decide whether the extension is Community self-guided, Team support, or Enterprise-assisted.
5. Regenerate handoff evidence at the end of the extension.

Do not convert missing evidence into pass for the sake of pilot extension.
