## Headline

DecisionAtlas helps software teams recover the decision memory inside real codebases.

## Subheadline

Deploy it in your own environment, import selected public or private repositories, review decision candidates, ask why-search questions, detect bounded drift, and export release-ready evidence.

## Who It Is For

- Small engineering teams maintaining private repositories.
- Technical leads who need to explain why architecture changed.
- Product or platform teams preparing a release handoff.
- Consulting teams that need a repeatable Code Decision Audit for client projects.

## What DecisionAtlas Does

- Imports repository code and documentation into a workspace.
- Extracts candidate decisions with source-backed evidence.
- Lets reviewers accept, reject, supersede, or revisit decisions.
- Answers why-search questions with citations when evidence is available.
- Detects bounded drift between accepted decisions, source changes, and governance rules.
- Generates release evidence, readiness history, team handoff reports, and Code Decision Audit reports.

## Product Route

DecisionAtlas is self-hosted/private-deployment-first.

| Tier | Best Fit | Buyer Outcome |
| --- | --- | --- |
| Community | Local evaluation and public-repo proof | Validate the workflow before buying. |
| Team Self-hosted | Small teams with private repositories | Run DecisionAtlas inside the team's environment with bounded support. |
| Enterprise Self-hosted | Private network or assisted deployment | Add deployment support, recovery guidance, and custom handoff expectations. |

## Pilot Offer

Start with one repository and one decision-governance outcome:

1. Deploy the self-hosted package.
2. Import one representative repository.
3. Review high-value decision candidates.
4. Run why-search and drift checks.
5. Generate release evidence and a Code Decision Audit report.
6. Decide whether Team Self-hosted or Enterprise Self-hosted is the right commercial fit.

## Proof Points To Show

- Package verification and clean install rehearsal.
- Release evidence and readiness evidence history.
- Real-repository benchmark comparison or fixed-pool trend evidence.
- Team handoff report.
- Code Decision Audit report.
- Screenshot or browser walkthrough of review, why-search, drift, governance, and evidence pages.

## Explicitly Not Included Yet

DecisionAtlas is not currently positioned as a full managed SaaS product. The current commercial route does not include billing, hosted multi-tenancy, Marketplace or self-service OAuth installation, hosted secret vault, runtime license enforcement, or hosted managed operations.

## Call To Action

Use DecisionAtlas for a bounded Code Decision Audit first. If the report is useful, convert the same deployment into a Team Self-hosted or Enterprise Self-hosted pilot.
