# Pilot Support, Renewal, And Upgrade Boundary

This document explains the support response boundary and what happens after a paid pilot. It is a proposal template, not a service-level agreement, legal contract, or runtime license policy.

## Support Response Boundary

The paid pilot can include bounded operator support for:

- self-hosted package startup
- environment configuration review
- health and smoke checks
- evidence generation guidance
- selected repository import troubleshooting
- Code Decision Audit handoff
- backup/restore/upgrade rehearsal interpretation

The paid pilot does not include:

- managed hosted operations
- 24/7 production incident response
- customer infrastructure administration
- unlimited repository onboarding
- billing system setup
- hosted secret vault operation
- Marketplace or self-service OAuth setup
- runtime license enforcement
- enterprise SSO integration

## Renewal Path

At the end of the pilot, the customer can choose:

- stop after the Code Decision Audit handoff
- extend the pilot for more evidence or a second repository
- convert to Team Self-hosted annual support
- request Enterprise Self-hosted assisted deployment or custom governance reporting
- request future hosted managed service discussion after self-hosted value is proven

## Upgrade Path

Upgrade discussions should reference:

- package verification evidence
- readiness evidence history
- backup/restore/upgrade rehearsal evidence
- release evidence
- private-repo evidence boundaries
- support and customization scope

Do not describe upgrade readiness as clean pass unless backup, restore, migration, post-upgrade validation, and rollback evidence are present or the limitation is disclosed.

## Customer-Specific Records

Keep these outside the public repository:

- filled quote
- signed agreement
- payment data
- customer contact details
- private repository names when confidential
- provider keys
- repository tokens
- `.env` files
- private source code
- private issue or pull request text

## Deferred Capabilities

The current self-hosted pilot package still defers:

- billing
- hosted multi-tenancy
- Marketplace or self-service OAuth
- hosted secret vault
- online license server
- runtime license enforcement
- enterprise SSO
- managed hosted operations
