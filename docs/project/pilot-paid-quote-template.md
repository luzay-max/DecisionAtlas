# Paid Pilot Quote Assumptions Template

[Proposal Kit](pilot-commercial-proposal-kit.md) | [Acceptance Checklist](pilot-acceptance-checklist.md) | [Support And Renewal](pilot-support-renewal-upgrade-boundary.md)

---

This is an editable draft assumptions template for a paid self-hosted DecisionAtlas pilot. It is not a legal contract, invoice, checkout flow, payment instruction, or signed customer agreement.

Filled customer-specific quotes must stay outside the public repository or in a private customer-controlled delivery folder.

## Draft Offer

| Field | Template Value |
| --- | --- |
| Offer name | Team Self-hosted paid pilot |
| Pilot duration | 2-4 weeks unless otherwise agreed |
| Target repository scope | 1 representative repository |
| Deployment model | Customer-controlled self-hosted or operator-controlled private environment |
| Primary outcome | Code Decision Audit plus self-hosted readiness evidence |
| Draft price assumption | Replace with private customer-specific quote |
| Renewal option | Convert to Team Self-hosted annual support or Enterprise Self-hosted deployment support |
| Extension option | Add repository scope, operator support, or custom governance reporting |

## Included Deliverables

- Self-hosted package and operator setup guidance.
- Pilot deployment checklist.
- One representative repository import or documented operator-guided blocker.
- Decision review walkthrough.
- Why-search and drift review examples.
- Package verification evidence.
- Clean install rehearsal evidence when available.
- Release evidence and hosted/operator readiness evidence.
- Readiness evidence history entry.
- Real-repo benchmark comparison evidence.
- Private-repo pilot evidence verification when private repository value is claimed.
- Backup/restore/upgrade rehearsal evidence for continuity claims.
- Team handoff report when team workflow is part of scope.
- Code Decision Audit report.

## Explicit Exclusions

This quote assumption template does not include:

- billing implementation
- hosted multi-tenancy
- Marketplace or self-service OAuth
- hosted secret vault
- online license server
- runtime license enforcement
- enterprise SSO
- managed hosted operations
- unlimited repository import scope
- legal contract generation
- payment processing

## Evidence Conditions

Any claim marked `warning`, `blocking`, `operator_guided`, `known_limitation`, or `not_provided` remains visible in the proposal and handoff. Do not convert non-clean evidence into pass.

## Customer-Specific Private Fields

Fill these only in a private customer-controlled copy:

- customer legal name
- billing contact
- payment terms
- purchase order or invoice details
- negotiated price
- signed legal terms
- private repository names if they are confidential
- support contact details
